# Festival Sape & Lumière

Landing page événementielle en HTML5, CSS3 et JavaScript Vanilla.

## Fonctionnalités

- Navigation fluide
- Menu hamburger sous 768 px
- Compte à rebours
- Onglets Vendredi / Samedi / Dimanche
- Filtres Tous / Musique / Mode / Art & Lumière
- FAQ en accordéon avec un seul panneau ouvert
- Réservation WhatsApp avec message pré-rempli
- Validation du formulaire
- Animations au scroll
- Responsive 320 px → 1920 px

## Configuration

Dans `script.js`, renseigner :

```js
const WHATSAPP_NUMBER = "242XXXXXXXXX";
const FESTIVAL_OPENING_DATE = "AAAA-MM-JJTHH:MM:SS+01:00";
```

Remplacer ensuite les placeholders dans `index.html` :

- [À CONFIRMER]
- [ARTISTE À CONFIRMER]
- [CRÉATEUR À CONFIRMER]
- [À RENSEIGNER]

Les images actuelles sont des visuels Unsplash de démonstration. Pour la production, il est recommandé de les télécharger, les convertir en WebP et les servir localement.
